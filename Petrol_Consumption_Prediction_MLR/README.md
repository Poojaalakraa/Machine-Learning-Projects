# Petrol Consumption Prediction using Multiple Linear Regression

## Project Overview
This project predicts petrol consumption based on driver's license percentage, petrol tax, paved highways, and average income using Multiple Linear Regression.

## Algorithm
- Multiple Linear Regression

## Libraries Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Dataset
- Petrol_Consumption.csv

## Input
- Driver's License Percentage
- Petrol Tax
- Paved Highways
- Average Income

## Output
- Predicted Petrol Consumption

- Google Colab
