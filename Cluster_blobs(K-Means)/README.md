# K-Means Clustering

## Overview
This project implements the K-Means Clustering algorithm using Python and Scikit-learn. K-Means is an unsupervised machine learning algorithm that groups similar data points into clusters based on their features.

## Dataset
- Cluster Blobs Dataset
- Features: X1, X2

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Workflow
- Load the dataset
- Visualize the data
- Apply K-Means Clustering
- Plot the clusters and centroids

## Result
The algorithm successfully grouped the data into meaningful clusters and identified the centroid of each cluster.
